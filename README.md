1. CARC (Claim Adjustment Reason Code)
 • Purpose: Explains the financial adjustment applied to a submitted claim or service line.
 • Format: Numeric (e.g., 16, 96, 197).
 • Example:
  – 197: Precertification/authorization/notification absent.


2. RARC (Remittance Advice Remark Code)
 • Purpose: Provides additional narrative context or instructions to supplement the CARC.
 • Format: Alphanumeric (e.g., N130, M15).
 • Example:
  – N130: Consult plan benefit documents/guidelines for service restrictions.
